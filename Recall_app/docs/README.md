## 文档维护约定

- 文件名使用中文，代码标识、环境变量和命令保留原文。
- 不在文档中记录真实 Token、API Key、设备私有数据或本地 `.dev.vars` 内容。
- 测试数量和构建产物哈希只写入带日期的验收报告，常规文档只维护可重复执行的验证命令。
- Schema 版本、Prompt 版本和调度器版本必须与源码常量一致。
